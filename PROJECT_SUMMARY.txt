Bug #1: Input Validation (Commit: b230b40)
-------------------------------------------
Problem: No validation of user inputs
Solution: 
  - Added comprehensive validation for all inputs
  - Config-based min/max limits
  - Clear error messages for invalid input
  - Prevents negative values and out-of-range inputs

Bug #2: Integer Overflow (Commit: f5191e9)
-------------------------------------------
Problem: float/int types caused overflow with large values
Solution:
  - Changed data types: float → long double
  - Changed tenure type: int → long int  
  - Used powl() for high-precision calculations
  - Handles loans up to 100 billion without overflow

Bug #3: Hardcoded Values (Commit: 08af5a6)
-------------------------------------------
Problem: Validation limits hardcoded in source
Solution:
  - Created config.txt for external configuration
  - Implemented Config class for parsing
  - All limits and settings externalized
  - Easy to modify without recompilation

  R = Monthly interest rate (annual rate / 12 / 100)
  N = Tenure in months
